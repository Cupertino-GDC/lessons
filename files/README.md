# Downloadable lesson files

Commit starter projects, sprite packs and other lesson assets here, one
folder per lesson id:

    files/unity-platformer/starter.unitypackage

Reference them from a lesson's `files` array with `"kind": "repo"`.

Large binaries bloat git history forever. If an asset is more than a few MB,
host it externally and use `"kind": "link"` instead.
